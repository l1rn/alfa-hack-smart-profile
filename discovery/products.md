## Инсайты для конвейера (не только «список продуктов»)

1. **Подбор = дерево вопросов**, как на калькуляторе: ИП/ООО → залог да/нет → срок бизнеса ≤9 / >9 мес → цель (оборот / инвестиция / кассовый разрыв / маркетплейс / рефинанс).
2. **Модификаторы ставки — отдельные «аддоны»**: Подписка (овердрафт / ВКЛ / селлер) + «Защита бизнеса». В MVP их можно моделировать как чекбоксы, влияющие на ставку и срок транша.
3. **Форма выдачи важнее бренда продукта**: одной суммой / транши (ВКЛ) / лимит на счёте (овердрафт) / карта. Клиент без экспертизы думает «мне нужны деньги на закупку», а не «мне нужна НКЛ».
4. **Скорость воронки с сайта**: заявка → решение ~5 мин / предодобрение ~3 мин → лимит за 1 день → звонок менеджера на подписание. Это готовые статусы заявки.
5. **Правила использования денег** («как нельзя тратить») — готовый блок compliance на стороне банка (запрет на дивиденды, ценные бумаги, погашение других кредитов и т.д.).
6. **Селлеры** — сильная персона кейса: лимит растёт от оборотов MP; альтернатива «раннему выводу выручки».
7. **«Деньги на дело»** на странице lombard = кредит/линия **под залог без финдоков**, в т.ч. для стартапов «с 0». Не путать с Альфа-Старт (до 1 млн без залога) — его ещё нет в дампах.
8. **Факторинг / гарантия / лизинг** в меню рядом с кредитами — для подбора «не только кредит», если у клиента отсрочка от покупателя или госзакупка.

## Черновик decision-tree для ЛК

```
цель?
  кассовый разрыв / платежи поставщикам → overdraft | creditcard
  регулярный оборот / закупки частями → creditline | creditsellers (если MP)
  разовая инвестиция / развитие → businesscredit
  новый бизнес ≤9 мес, мало суммы → alfastart (допарсить)
  новый/любой + есть залог, без финдоков → lombard («Деньги на дело»)
  есть кредит в другом банке → refin
  авто/недвижимость → autocredit | businessipoteka
  отсрочка от покупателя → factoring (допарсить)
```
